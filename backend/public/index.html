BlitzForge

Реестр модов для World of Tanks Blitz.

API

  • GET /api/mods — список одобренных модов
  • GET /api/mods?type=resource — фильтр по типу
  • GET /api/mods?q=дождь — поиск
  • GET /api/mods/:id — один мод

Публикуется только то, что прошло ревью

Реестр отдаёт мод, только если у него review.status == "approved". Фильтр стоит в общем слое, а не в каждом обработчике, чтобы новая ручка не могла про него забыть. Мод на рассмотрении отвечает 404, а не «доступ запрещён»: иначе по кодам ответов читается сама очередь.

Чего здесь нет

Реестр хранит метаданные, а не файлы игры. Моды, которые правят ресурсы Wargaming, распространяются как патчи поверх клиента пользователя — исходные ресурсы инструмент извлекает из его собственной копии.
